# Classes, locations and projects

An owner enables each dimension in Settings, adds named values, and chooses which accounts require them. New invoice and bill lines, journal postings and bank filings refuse missing required values or inactive values. Deactivating a name preserves historical coding; add a new name instead of renaming posted evidence. Turning a dimension off suspends its new-line requirement without deleting history.

Choose coding on invoice, bill, journal and receipt lines, vendor credits, write-offs and recurring bill templates. Bank rules can match exact dimension values and set them on each split; a blank action keeps the incoming value. The first matching rule keeps precedence and each filing retains its reviewed rule revision. Vendor defaults, document coding and the latest human filing feed suggestions; people retain control of accepting them. Payroll coding in Settings maps each future payroll line role; it does not rewrite posted payroll. Processor coding in the same Settings section maps future Stripe sales, refunds, fees, clearing, bank and invoice-receivable lines. A missing required value holds the provider item with a reason; fixing the mapping and syncing again posts it once. Checkout and clearing imports share these mappings. A mapping edit never rewrites an earlier posting, including an Unassigned one. Each atomic posting checks that its mapping revision is still current.

Reports offers P&L and balance-sheet columns by class, location or project on cash and accrual. Unassigned postings remain visible; inactive names retain their historical columns, and each row sums to Total. Balance-sheet columns include all opening activity and calculated fiscal-year earnings. A column can be out of balance when opposite posting lines have different coding; Total remains the whole statement.

General ledger, trial balance, P&L, balance sheet, sales by customer/item, expenses by vendor, cash flow, sales tax, ageing, the six open-item library variants, transactions and journal reports can filter one enabled dimension value, including inactive historical values and Unassigned. Statement filters also apply to prior-period/year, month, quarter, YTD and customer columns. Choose a dimension filter or dimension columns, rather than combining both. Figures, running balances, comparison percentages and existing report downloads retain their scope. Cash-flow classification still judges each whole entry; its selected posting contributions and opening/closing cash retain the filter and show when differently coded sides do not tie. Sales tax filters issued and settled sale/tax shares, early-payment columns and liability evidence. Ageing allocates original document line shares and subtracts their cumulatively rounded settlements. Unapplied payments retain their own control-line coding, and unapplied credits their source coding. These selected subledger shares can differ from separately coded control-account postings; the full report retains the whole-book tie. Choose All dimensions to check the whole books. Accountant package financial reports and ledger CSV retain the selected dimension; the ZIP/JSON explicitly label close checks, provider balances, reconciliations, audit and document inventory as whole-business evidence.

Saved custom reports can keep the same dimension filter, or use class/location/project columns for P&L and balance sheet. Formula operands, additive source downloads, source-report links and management-package reports use the saved selection. Sharing continues to apply the reader's current financial authority. Project profitability links income, costs and profit to those same source lines. Its time table uses the native time project with the same name, and values unbilled hours at current service rates.

Annual budgets accept optional class and location on each account/month amount. CSV adds optional `Class` and `Location` columns to `Account,Month,Amount`. Easel import maps each line to an account and can explicitly map departments to classes and locations. Prior-year copying retains its source coding. Budget versus actual filters a dimension value, including Unassigned, and carries it into plan, actual, variance, percentage and downloaded evidence.

Books → Review can move bank or manual journal lines to another dimension with linked correcting entries. Original postings stay unchanged; locked periods refuse correction. Posted invoices, credits and bills currently require a document correction because their cash recognition follows settlements.

Payment, reconciliation and audit report families and nonstatement dimension splits, remaining non-processor generated-control-line source coding, and settlement-aware document recoding still need completion and public-door proof.
